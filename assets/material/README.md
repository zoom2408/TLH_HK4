# assets/material

Nơi lưu trữ giáo trình / sách / PDF nguồn dùng cho các trang ôn tập.

Thả file PDF trực tiếp vào thư mục này, sau đó trỏ link tải trong `index.html` của môn tương ứng tới đường dẫn tương đối, ví dụ:

```html
<a href="../assets/material/ten-file.pdf" download>Tải PDF</a>
```

## File hiện tại

- `Giao trinh Tam ly hoc tam linh - ton giao_Vu Dung.pdf` — giáo trình gốc Vũ Dũng, dùng cho trang `tlh-ton-giao/`. **Chưa được tải lên** — hãy thêm file này vào thư mục để nút "Tải giáo trình gốc Vũ Dũng (PDF)" trên trang hoạt động.

Khi thêm giáo trình cho môn khác, cứ thả file PDF vào đây (không cần thư mục con) và cập nhật link tương ứng trong trang môn đó.
