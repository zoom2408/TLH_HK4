# assets/img

Nơi lưu ảnh minh họa dùng trong giao diện (landing page, hero section, các trang môn...).

## File cần có

- `hero.png` — ảnh minh họa nhân vật trong hero section của landing page (`index.html`). **Chưa có trong thư mục** — cần thả file vào đây để hình hiển thị đúng.

Khi thêm ảnh cho trang khác, cứ thả file trực tiếp vào đây (không cần thư mục con) và trỏ đường dẫn tương đối tới `assets/img/ten-file.png` trong HTML/CSS tương ứng.
